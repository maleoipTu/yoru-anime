# Дизайн Yoru: токены и правила

Yoru — «ночь». Интерфейс — ночное небо перед сеансом: глубокий угольный фон, тёплое коралловое свечение
на горизонте и редкие звёзды. Смелость тратим в одном месте — **шапки разделов** (звёздное небо
и короткая полоса «зари» под заголовком). Всё остальное — спокойное, с большим количеством воздуха.

## Цвет

| Токен | Значение | Роль |
|---|---|---|
| `bg` | `#0E0E11` | фон окна |
| `panel` | `#16161B` → градиент `#1C1C23 → #141418` | карточки и панели |
| `raised` | `#1F1F26` | кнопки, поля, плитки |
| `line` | `#2A2A33` (тоньше — `#24242C`) | обводки и разделители |
| `text` | `#F5F5F7` | основной текст |
| `muted` | `#9C9CA8` | подписи |
| `accent` | `#FF4D67 → #FF8A3D` | действие, активное, «заря» |
| `soft` | `#3A1820` | подложка выбранного |
| `night` | `#1A1428 → #0E0E11` | небо в шапках, звёзды `#FFFFFF` 20–70 % |

Акцент — только для действия и состояния «выбрано/сейчас». Звёзды — только в шапках (боковая панель,
герой каталога, шапка Android) и никогда под текстом основного содержимого.

## Отступы

Шкала: **4 · 8 · 12 · 16 · 24 · 32 · 48**.

- Между секциями страницы — 32 (крупные блоки, «герой» → каталог — 40).
- Внутри панели — 28 (Windows) / 20 (Android).
- Между заголовком секции и содержимым — 16.
- Между соседними кнопками — 12; между строками списка — 10.
- Поля страницы: Windows 40 по бокам, 32 сверху; Android 20.
- Сетка каталога: Windows — 24 по горизонтали, 36 по вертикали; Android — 16 и 28.

## Радиусы

| Токен | Значение | Где |
|---|---|---|
| `r-sm` | 8 | пункты выпадающих списков, бейджи |
| `r-md` | 12 | кнопки, поля, постеры, плитки серий |
| `r-lg` | 20 | панели и карточки секций |
| `r-xl` | 24 | герой, шапка профиля, окно входа |
| `pill` | 18+ | чипы фильтров |

Чем крупнее и «важнее» поверхность, тем больше радиус — одинакового радиуса на всём нет.

## Типографика

Segoe UI (Windows) / системный sans-serif и sans-serif-medium (Android). Без капса в подписях:
метки секций пишутся обычным регистром.

| Роль | Windows | Android |
|---|---|---|
| Заголовок страницы | 32, SemiBold + полоса «зари» 44×3 | 26, Bold |
| Заголовок героя | 30, Bold | 24, Bold |
| Заголовок секции | 20, SemiBold | 19, Bold |
| Подзаголовок / вводный текст | 14, `muted` | 14, `muted` |
| Основной текст | 14, межстрочный 22–24 | 15, +5dp |
| Подпись | 12, `muted` | 12, `muted` |

## Контролы

- Кнопки и поля — высота ~44 (Windows: отступы 20×12) / 48–52dp (Android).
- Наведение на кнопку — мягкая светлая подложка поверх, нажатие — сжатие до 98 %.
- Основная кнопка — градиент акцента со свечением; при наведении свечение сильнее.
- Поле в фокусе — акцентная обводка, при наведении — чуть светлее линия.
- Активный пункт навигации — подложка, уходящая в прозрачность, и вертикальная полоса акцента слева.

## Глубина

- `Shadow` — мягкая тень под постерами и всплывающими окнами.
- `AccentGlow` — свечение основной кнопки; `CardGlow` — подсветка постера при наведении.
- Карточка каталога на Windows при наведении поднимается на 6 px, постер получает акцентный контур.

## Правила секций

1. У страницы один крупный заголовок с полосой «зари» под ним; секции — заголовки 20 без полос.
2. Секция — панель `panel` с радиусом 20 и обводкой `line`, внутри 28.
3. Разделитель внутри панели — линия 1 px `line` с отступами 24 сверху и снизу.
4. Пустые состояния — луна ☾ и одна фраза-действие.
