## Установка

**Windows.** Скачайте [Yoru-Setup.exe](https://github.com/maleoipTu/yoru-anime/releases/download/nightly/Yoru-Setup.exe) и запустите — права администратора не нужны, Yoru ставится в профиль пользователя и дальше обновляется сам. Нужен Microsoft Edge WebView2 Runtime (в Windows 11 уже есть). Переносная версия без установки — `Yoru-Windows.zip` в [той же сборке](https://github.com/maleoipTu/yoru-anime/releases/tag/nightly).

**Android.** Скачайте [Yoru-Android.apk](https://github.com/maleoipTu/yoru-anime/releases/download/nightly/Yoru-Android.apk) на телефон и откройте; если Android спросит, разрешите установку из этого источника. Приложение само сообщит о новой версии.

При первом запуске Yoru попросит войти или зарегистрироваться — аккаунт нужен для профиля, очков, списков и друзей.

## Как устроено

- **Windows** — C# / WPF (.NET 10), одно окно со страницами; плеер — HTML5 + hls.js внутри WebView2, видео идёт через встроенный прокси приложения.
- **Android** — Java, нативные элементы интерфейса, плеер на Media3 ExoPlayer.
- **Сервер** — Supabase: аккаунты, Postgres с правилами доступа (RLS) и серверными функциями для очков, покупок и модерации, хранилище аватаров и баннеров. Схема — в [`supabase/migrations`](supabase/migrations), проверки — в [`supabase/tests`](supabase/tests).
- **CI** — GitHub Actions собирает и тестирует обе платформы и базу, а каждая сборка из `main` публикуется как pre-release [nightly](https://github.com/maleoipTu/yoru-anime/releases/tag/nightly).

Каталог и видео — через официальный API YummyAnime (`api.yani.tv`); API заявлен владельцем для личного использования. Yoru — независимый клиент; доступность серий и видео зависит от YummyAnime и поставщиков плееров.

## Списки, достижения, друзья и отзывы (Android 0.7.0, Windows 0.4.0)

- **Списки** «Смотрю», «Запланировано», «Просмотрено», «Брошено» хранятся в аккаунте и общие для Android и Windows. Аниме само попадает в «Смотрю» после первой засчитанной серии, а в «Просмотрено» — после последней. Статус меняется вручную в карточке аниме. Списки открываются переключателем в разделе «Избранное».
- **Достижения**: 15 штук — за серии, ночной просмотр, досмотренные аниме, дни подряд, отзывы, друзей и коллекцию украшений. Дают очки, а некоторые — эксклюзивные украшения, которые не продаются.
- **Дни подряд (streak)**: первая засчитанная серия за день продлевает серию дней и даёт бонус +2 очка за каждый день подряд, максимум +20.
- **Сезонные украшения** продаются ограниченное время: хэллоуинские — до 3 ноября, новогодние — с 20 декабря по 14 января. Купленные остаются навсегда.
- **Друзья**: поиск по нику, заявки, публичный профиль с уровнем, витриной, достижениями и статистикой списков. Лента «Что смотрят друзья».
- **Оценки и отзывы**: оценка от 1 до 10 и короткий отзыв к любому аниме, средняя оценка пользователей Yoru и отзывы других в карточке аниме.
- **Плеер**: автопереход к следующей серии с отсчётом 5 секунд (можно остаться или выключить в настройках плеера) и кнопка «+85 с» для пропуска опенинга в первые 5 минут серии.
- **Нативный плеер Windows**: Kodik теперь открывается в собственном плеере Yoru — без рекламы и скриптов провайдера, с качеством, скоростью, перемоткой (←/→), паузой (пробел), пропуском опенинга (S), следующей серией (N) и сохранением позиции. Видео идёт через встроенный прокси приложения. Кнопка «Плеер Yoru ⇄ плеер сайта» переключает на запасной плеер сайта. При первой сборке скачивается hls.js (Apache-2.0) фиксированной версии.

Списки и отзывы публичные: их видят другие пользователи в профиле и карточке аниме. Заявки в друзья видят только их участники.

## Аккаунты, очки и украшения профиля (Android 0.6.0, Windows 0.3.0)

В Yoru появились аккаунты на базе Supabase. Вход и регистрация — по почте и паролю. Без входа приложение работает как раньше.

- **Профиль**: аватар (первая буква ника или постер из витрины), имя, ник `@username`, строка статуса до 80 символов и витрина «Любимое аниме» — до 6 тайтлов из избранного.
- **Очки за просмотр**: 10 очков за серию и ещё +5 за первую серию нового аниме. Серия засчитывается после реального воспроизведения: на Android — 60% длительности, но от 5 до 12 минут; на Windows — 10 минут. Пауза в зачёт не идёт. За одну и ту же серию (аниме + номер) очки даются один раз, даже при смене озвучки. Между начислениями должно пройти не меньше 4 минут, лимит — 40 серий в сутки. Плеер сайта на Android очки не начисляет: он не сообщает о ходе просмотра.
- **Уровни**: уровень N открывается после 50·(N−1)² заработанных очков (2-й — 50, 3-й — 200, 5-й — 800). Траты уровень не снижают.
- **Украшения** покупаются за очки, часть требует уровня: 7 рамок аватара (градиентные, со свечением, анимированные «Северное сияние» и «Затмение»), 7 значков рядом с ником и 7 цветов ника, включая градиенты. Базовые рамка, значок и цвет бесплатны. Купленное надевается сразу, значок можно снять.

На Android профиль открывается кнопкой-аватаром в шапке каталога, на Windows — карточкой в боковой панели.

### Подключение базы данных

1. Создайте проект на https://supabase.com (бесплатного тарифа достаточно).
2. Откройте **SQL Editor**, вставьте содержимое `supabase/migrations/20261030000000_accounts.sql` целиком и нажмите **Run**. Скрипт создаёт таблицы `profiles`, `decorations`, `inventory`, `watch_awards`, правила доступа (RLS), функции и каталог украшений. Повторный запуск безопасен.
3. В **Project Settings → API** скопируйте *Project URL* и *anon public key* в `supabase.properties` в корне репозитория:
   ```properties
   url=https://xxxx.supabase.co
   anon_key=eyJ...
   ```
   Вместо файла можно задать переменные окружения `YORU_SUPABASE_URL` и `YORU_SUPABASE_ANON_KEY`. Anon-ключ публичный и рассчитан на встраивание в приложения. **Service-role-ключ в приложение не вставляйте.**
4. В **Authentication → Providers → Email** решите, нужно ли подтверждение почты. Если оно включено, после регистрации приложение попросит подтвердить почту и войти.
5. Пересоберите приложения. Android читает настройки при сборке; Windows-сборка кладёт `supabase.properties` рядом с `Yoru.exe`, его можно поменять и без пересборки.

Как устроена защита: клиент может напрямую менять только имя, статус, аватар и витрину своего профиля. Очки, уровень, покупки и надетые украшения меняются только серверными функциями `award_watch`, `buy_decoration` и `equip_decoration` с проверками баланса, уровня и владения. Время просмотра сообщает клиент, поэтому повторы, паузы между начислениями и дневной лимит ограничивают накрутку, но полностью её не исключают. Новые украшения можно добавлять строками в таблицу `decorations` без обновления приложения: стиль задаётся JSON-полем `style`.

Сессия хранится в приложении: на Windows — под защитой DPAPI (`%LOCALAPPDATA%\Yoru\account.session`), на Android — в приватных настройках приложения.

## Нативный плеер

- Прямое воспроизведение HLS/MP4 на Media3 ExoPlayer. Для Kodik приложение получает только страницу, параметры запроса и список видеопотоков; JavaScript провайдера и рекламные поля ответа не выполняются.
- Свой интерфейс: пауза, шкала времени с буферизацией, перемотка ±10 секунд кнопками и двойным касанием, качество из доступных вариантов, скорость 0.5–2×, выбор серии и полный экран с поворотом.
- Позиция сохраняется каждые пять секунд, при смене качества и уходе из приложения. После завершения серии повторное открытие начинает её сначала. Настройки скорости и предпочитаемого качества сохраняются.
- При сворачивании видео ставится на паузу; аудиофокус и отключение наушников обрабатывает Media3. Экран остаётся включённым во время воспроизведения.
- Прямое подключение реализовано для Kodik. CVH, Aksor и Alloha доступны через явно подписанную кнопку плеера сайта, где может быть реклама. Автоматического перехода к рекламному плееру нет.

Рекламные вставки, уже вмонтированные в сам видеофайл, этот способ не удаляет. Доступность потоков и их адреса зависят от провайдера; при изменении формата запросов потребуется обновление клиента. Подписанные адреса потоков не сохраняются в библиотеке и не входят в исходники.

Проверки: 27 модульных тестов, сборка APK и Android Lint. Для необязательной проверки реального воспроизведения на подключённом устройстве или эмуляторе предусмотрен тест:

```powershell
.\android\gradlew.bat -p android connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.live=true
```

Он использует публичный API и проверяет реальное видео, восстановление позиции, паузу, перемотку, смену качества, полный экран и следующую серию. Отдельный ручной workflow **Android player smoke test** сохраняет отчёт и снимки экрана. Media3 1.8.0 выбран для совместимости с используемым compileSdk 35.

В мобильном каталоге используются переиспользуемые карточки и загрузка страниц по 24 аниме. Карточка прокручивается целиком, включая выбор серии; при возврате из просмотра восстанавливается последняя открытая серия. Локальная библиотека Android независима от библиотеки ПК.

## Первый запуск на Windows

1. Распакуйте архив целиком в отдельную папку.
2. Запустите `Yoru.exe`. Установка .NET не требуется: стабильная .NET 10 включена в переносную сборку.
3. Каталог загрузится автоматически: публичный ключ приложения YummyAnime уже встроен по запросу пользователя. Вводить ключ и входить в аккаунт не нужно.
4. Найдите аниме, откройте карточку, выберите озвучку, плеер и серию, нажмите **Смотреть**, затем кнопку ▶ в самом видео.

Запросы отправляются в официальный API https://api.yani.tv/. Пароль или пользовательский Bearer-токен не требуется. Чтобы заменить встроенный ключ, откройте **Настройки** и укажите другой публичный ключ `X-Application` из https://yummyani.me/dev/applications, затем нажмите **Проверить и подключить**. Заменённый ключ сохраняется только после успешной проверки. Встроенный публичный ключ присутствует в исходниках и сборке; пользовательских токенов и паролей в ней нет.

Для встроенного видео требуется **Microsoft Edge WebView2 Runtime**. Если его нет, в окне просмотра есть ссылка на официальный сайт Microsoft: https://developer.microsoft.com/microsoft-edge/webview2/.

## Возможности версии 0.2

- Каталог: поиск по названию, сортировка по рейтингу, популярности и году; случайная сортировка; фильтр по статусу; загрузка следующих страниц.

- Просмотр: раздельные поля озвучки, плеера и серии; предыдущая/следующая серия; F11 для полного экрана, Esc для выхода из него. Все поля доступны непосредственно в окне просмотра.
- Плееры открываются внутри iframe в собственном локальном HTTPS-контейнере приложения. Это исправляет ошибку прямого открытия Kodik и CVH. Адреса видео используются в том виде, в каком их возвращает API.
- «Другой плеер» сохраняет текущую серию и озвучку. Если подходящего источника нет, кнопка недоступна. При ручном выборе источника без нужной серии требуется явно выбрать доступный номер.
- Повторная загрузка, восстановление окна после ошибки и синхронизация выбранного источника с переходами между сериями. Ошибка в полном экране возвращает панель управления.
- Компактная карточка с панелью просмотра сверху, сворачиваемое описание, тёмные выпадающие списки, более крупные метаданные, блок продолжения на главной странице.
- Локальное избранное и история последних открытых серий. При повторном открытии карточки выбирается последняя серия и озвучка, если они по-прежнему доступны.
- Расписание с датами следующих серий в часовом поясе компьютера, если даты предоставлены API.
- Защита ключа с помощью Windows DPAPI. Всплывающие окна, загрузки файлов и запросы разрешений из встроенных плееров отключены.

## Данные

Библиотека: `%LOCALAPPDATA%\Yoru\library.json`.

Пользовательская замена ключа: `%LOCALAPPDATA%\Yoru\application.key`. Она зашифрована для текущей учётной записи Windows и имеет приоритет над встроенным публичным ключом. Если файл отсутствует, используется встроенный ключ. Папку с сохранённой заменой не следует переносить на другую учётную запись.

Данные встроенного плеера: `%LOCALAPPDATA%\Yoru\Player`.

История фиксирует **открытие серии**, а не её фактический досмотр. В нативном Android-плеере позиция хранится в приложении; в плеере сайта и Windows — зависит от провайдера. Синхронизация с аккаунтом YummyAnime и скачивание серий в эту версию не входят. Аккаунт Yoru хранит профиль, очки и украшения; избранное и история остаются локальными.

## Доступность API и видео

API требует ключ приложения и заявлен владельцем для личного использования. Для коммерческого применения необходимо согласование с владельцем API. Документация: https://api.yani.tv/.

Yoru — независимый клиент. Наличие видео, доступность в регионе, качество и работа озвучки определяются YummyAnime и поставщиками видео. Если поток недоступен, выберите другую озвучку/источник или откройте карточку на сайте. Нативный Android-плеер получает ссылки из ответа Kodik; Windows и резервный плеер сайта используют iframe.

## Сборка из исходников

Установите стабильный .NET SDK 10 или более новый совместимый SDK.

```powershell
dotnet publish Yoru/Yoru.csproj -c Release -r win-x64 --self-contained true -p:DebugType=None -p:DebugSymbols=false -o outputs/Yoru
dotnet run --project Tests/Tests.csproj -c Release -r win-x64 --self-contained true
```

Для первого восстановления зависимостей нужен интернет. NuGet-зависимость: Microsoft.Web.WebView2. Все изображения и образец каталога получены из YummyAnime; права принадлежат их правообладателям. Образец каталога загружен 29 октября 2026 года, рейтинги и доступность могут измениться.

Для Android нужны JDK 17 или 21, Android SDK Platform 35 и Build Tools 35.0.0. Gradle Wrapper включён в исходники.

```powershell
$env:ANDROID_HOME='C:\Android\Sdk'
.\android\gradlew.bat -p android assembleDebug testDebugUnitTest lintDebug
node Tests/player-host.test.mjs
```

Для подписанного release задайте `YORU_STORE_FILE`, `YORU_STORE_PASSWORD`, `YORU_KEY_PASSWORD` и выполните `build-android.ps1 -Release`. Ожидаемый alias ключа — `yoru`. Для обновления установленной release-версии требуется тот же ключ подписи. Не публикуйте keystore и пароль.
